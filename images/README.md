# Character images

Put your own PNG images here (transparent background recommended, all the same canvas size, e.g. 800×500).

| File | Required | When it shows |
|---|---|---|
| `basic.png` | ✅ | Idle (not typing) |
| `Left.png` | ✅ | Alternates with `Right.png` on each key press |
| `Right.png` | ✅ | Alternates with `Left.png` on each key press |
| `space.png` | optional | When you press **Space** |
| `T.png` | optional | When you press **T** |
| `1.png` | optional | When you press **1** |

Images are not included in this repo. Only use images you drew yourself or have permission to use.
